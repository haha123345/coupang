쇼핑 채널 유튜브 연결 (한 번만)

집 PC(hookshorts 가 있는 컴퓨터)에서 하세요. 5분이면 끝나요.

1파일 받기

⬇ 다운로드

Edge 에서 '안전하지 않을 수 있음' 이 뜨면 … → 유지 를 누르세요.

2받은 파일 실행

다운로드 목록에서 youtube_login_coupang.bat 을 클릭하세요.
파란 창 'Windows의 PC 보호' 가 뜨면 추가 정보 → 실행.

검은 창이 뜨고 잠시 설치가 진행돼요. hookshorts 폴더의 구글 로그인 파일을 알아서 찾아요.

3브라우저에서 쇼핑 채널 계정 고르기

구글 계정 선택 화면에서 쇼핑 채널(goditem20xx) 계정을 누르고 → 계속 / 허용.
'Google에서 확인하지 않은 앱' 이 나오면 고급 → 이동(안전하지 않음).

4메모장에 나온 값 3개 등록

메모장이 자동으로 열려요. 맨 윗줄 채널 이름이 쇼핑 채널인지 확인하고,
아래 링크를 열어 Name 칸과 Secret 칸에 메모장 내용을 그대로 복사해 넣고 Add secret. 이걸 3번 반복하세요.

👉 비밀값 등록 화면 열기

YT_CLIENT_ID · YT_CLIENT_SECRET · YT_REFRESH_TOKEN

끝! 매일 12시쯤 쇼츠 2편이 비공개로 올라가고, 텔레그램으로 '공개로 바꾸기' 링크가 와요.

다 끝나면 다운로드 폴더의 coupang_youtube_values.txt 는 지워 주세요.
