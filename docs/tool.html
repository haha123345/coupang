쿠팡수집 즐겨찾기 설치 (Edge)

새 버전 (실제 구매자 후기 포함)
예전에 만든 쿠팡수집이 있으면 즐겨찾기에서 오른쪽 클릭 → 삭제한 뒤 아래 방법으로 다시 만드세요. 복사 완료 창에 "후기 N개 포함"이 보이면 새 버전입니다.

방법 1. 끌어다 놓기 (10초)

  1. Ctrl+Shift+B 를 눌러 즐겨찾기 모음을 화면 위에 보이게 하세요.
  2. 아래 빨간 버튼을 마우스로 잡고 즐겨찾기 모음 위로 끌어다 놓으세요. (클릭하지 말고 끌기)

쿠팡수집

방법 2. 직접 추가 (끌기가 안 될 때)

  2. 주소창에 edge://favorites 입력 → 엔터
  3. 오른쪽 위 즐겨찾기 추가(☆+ 아이콘) 클릭
  4. 이름: 쿠팡수집 / URL: 복사한 코드 붙여넣기 → 저장

쓰는 법

  1. 쿠팡 상품 페이지를 연 상태에서 즐겨찾기 모음의 쿠팡수집 클릭
  2. "복사 완료" 창이 뜨면, 상품 목록 파일의 info: '' 작은따옴표 안에 붙여넣기

상품명·브랜드·가격·정가·평점·리뷰 수·한 달 구매자 수·사진 6장이 한 번에 복사됩니다.
